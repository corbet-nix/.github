# Corbet Nix community health files

This repository provides the default contribution policy and pull-request
template for `corbet-nix` repositories.

The canonical agreement for this organization is the neutral
[Individual Contributor License Agreement](CLA.md). Every published agreement
revision is preserved under an immutable annotated tag; version 1.0 is
[`cla-v1.0`](https://github.com/corbet-nix/.github/blob/cla-v1.0/CLA.md).
The `Immutable CLA version tags` repository ruleset blocks updates and
deletions of every `cla-v*` tag.

Repositories keep their own outbound `LICENSE` (default for this org:
`MIT OR Apache-2.0`) and may add project-specific build, testing,
provenance, or third-party-material instructions without duplicating the
contributor agreement.

Note: this `.github` repo's own `LICENSE` is CC-BY-3.0 for the Harmony CLA template text only, not the outbound license for contributions.
